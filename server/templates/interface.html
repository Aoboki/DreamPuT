Remote desktop of this Linux server in the browser (VNC / noVNC)

Desktop service not connected

On the server install a lightweight desktop + VNC + noVNC websockify (script: server/scripts/setup_server_desktop.sh). Then open this page and press Connect.

Default path after setup: /vnc/vnc.html?autoconnect=1 (login required)

Clipboard (Windows → server): 1) Copy text on your PC (Ctrl+C). 2) In the desktop frame open noVNC control bar (sidebar / panel icon) → Clipboard. 3) Paste there (Ctrl+V) — text is sent to the remote desktop, then paste inside the remote app (Ctrl+V). Some browsers ask permission for clipboard once — allow it. Login on this site protects access; VNC has no second password.
